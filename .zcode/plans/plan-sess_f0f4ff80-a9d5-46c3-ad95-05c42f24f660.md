# 前端视觉与动画优化方案（现代活泼风格 · 全页面）

## 总体思路
不换 UI 框架、不动业务逻辑和接口，只做纯视觉层改造：新增一个全局样式文件承载设计变量（渐变色、圆角、阴影、动效曲线），所有页面从这里取值，保证风格统一；同时给路由切换、页面入场、悬停微交互加上成体系的动画。

## 1. 新增全局样式基建
- 新建 `src/assets/styles/global.css`，在 `src/main.js` 中引入（element-plus 样式之后）
- 定义设计令牌（CSS 变量）：主色渐变 `#409eff → #66b1ff`、圆角（卡片 12px / 控件 8px）、阴影三档、统一动效时长与缓动（0.25s ease）
- 定义公共动画 keyframes：`fadeInUp`、`fadeIn`、`scaleIn`、`float`（漂浮装饰用）
- 统一 Element Plus 变量：`--el-border-radius-base: 8px`、主按钮渐变背景 + 悬停上浮阴影、dialog 弹入动画（scale+fade）、el-table 行悬停高亮、el-tag 圆角胶囊化
- 统一 `.page-header` / `.page-card` 公共类（替换 5 个视图里逐字复制的同款 CSS）
- 美化全局滚动条（细圆角渐变 thumb）

## 2. App 壳（App.vue）
- 路由切换动画：`<router-view>` 改为 `v-slot` + `<transition name="page" mode="out-in">`，淡入+轻微上移
- 侧边栏现代化：深色渐变背景（#1e2a3a → #304156），logo 区优化，菜单项悬停/激活加渐变高亮 + 左侧亮色指示条动画
- 登录页时隐藏侧边栏（`v-if` 判断路由），让登录页全屏展示
- 清理重复的 `.logo-text` 规则；移动端 drawer 同步新风格

## 3. 登录页（Login.vue）
- 全屏渐变背景 + 2-3 个缓慢漂浮的模糊光斑（`float` 动画）
- 登录卡片改为毛玻璃效果（`backdrop-filter: blur` + 半透明白），入场 fadeUp
- 输入框聚焦动效、登录按钮渐变背景 + 悬停上浮、错误提示 shake 一下

## 4. 预约申请页（BorrowApplication.vue）
- 表单卡片入场动画（分区依次 fadeUp 的错落感）
- 公告按钮保持渐变风格并统一到全局令牌；成功弹窗动画与新风格统一
- 公告 dialog、divider 分区标题样式统一

## 5. 甘特图页（BorrowGantt.vue)
- 任务条改为渐变背景 + 圆角 + 悬停阴影增强（保留现有 5 状态色系）
- 当前小时列高亮加轻微呼吸感；表头/网格线配色微调
- 页面入场动画

## 6. 设备管理 + 预约详情（EquipmentManagement / RentDetails）
- 表格容器统一圆角+阴影卡片化，行悬停高亮
- el-tag 状态胶囊化；编辑/导出 dialog 弹入动画
- 搜索栏卡片化；分页区域间距优化
- 只改模板 class 和 CSS，不动脚本逻辑

## 7. 时间段管理 + 时间选择器（TimeSlotManagement / TimeSlotPicker）
- 日历卡片悬停上浮阴影增强、选中日期渐变背景
- 时间点按钮悬停微缩放、选中态渐变
- slot 卡片边框强调色过渡

## 验证方式
- `npm run dev` 启动前端（后端可不起，样式不依赖接口），用浏览器逐页截图检查：登录、预约申请、甘特图、三个管理页（登录页可直接看，管理页路由守卫需要 token——会用 localStorage 注入假 token 绕过守卫查看样式，接口失败不影响布局检查）
- 检查 768px 以下移动端断点不破版
- 最后跑一次 `npm run build` 确认构建通过

## 不做的事
- 不删 tailwind/gantt 等未使用依赖、不动后端、不改业务逻辑与接口调用
